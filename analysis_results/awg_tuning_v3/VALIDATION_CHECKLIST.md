# AWG 기본 검증 체크리스트 — 통합 문서로 이동

v3 기본 검증과 v4 추가 검증을 [통합 체크리스트](../awg_tuning_v4/VALIDATION_CHECKLIST.md)로 합쳤습니다.
각 항목의 실행 세대, 현재 소스 일치 여부, 현재 v4에서 다시 실행하지 않은 범위를 구분했습니다.

기존 v3 체크리스트의 완료 기록은 v3 당시 결과이며 현재 v4 전체 재실행을 의미하지 않습니다.
합치기 전 문서는 [v3 원본](../awg_tuning_v4/checklist_sources/v3_VALIDATION_CHECKLIST.md)에 보존했습니다.
