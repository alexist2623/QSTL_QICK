# 이전 DC/RC 대표 파형 두 구간의 독립 검토

보존된 `physical_compensation_100x100_20261015`의 두 PNG, 원시 scope IEEE block, 실제 명령 word와 정수 모델을 대조했습니다. 기존 offset·전역 시간 정렬·기준·판정은 바꾸지 않았으며 장비에 접속하지 않았습니다. 원본 PNG와 아래 연속 파형 PNG 두 장 모두 직접 열어 확인했습니다.

**Point 5050의 약 −300 mV는 고정전압 DC 보상에 실제로 명령된 짧은 펄스입니다. Point 9999 앞의 약 −100 mV는 이전 Point 9998의 DC 보상 끝부분입니다.** 기존 대표 그림의 모델 표시에는 각각 짧은 구간을 놓친 문제와 이전 포인트를 포함하지 않은 문제가 있습니다. 이 검토로 물리 DC 면적이나 정밀 타이밍이 PASS라는 결론을 새로 내리지는 않습니다.

## 1. 고정전압 300 mV / RC τ10 µs의 Point 5050

Point 5050은 100×100 sweep의 `(50, 50)`입니다. −300..+300 mV를 짝수인 100점으로 나누었으므로 중앙 포인트도 정확한 0 mV는 아닙니다. 양 채널 요청은 **+3.030303 mV**, 실제 정수 명령의 nominal 전압은 **+3.326455 mV**입니다. 이 작은 양의 면적을 고정전압 모드는 약 −300 mV의 **짧은** 펄스로 상쇄합니다. 설정한 300 mV는 보상 진폭의 크기이며, 부호는 누적 면적과 반대입니다.

실제 word `0147000000000000000000000000000000002fe8`은 DC 고정전압 명령입니다. pre-DC 정수 면적은 +1,790,946 effective-code·sample이고, 보상 run은 다음과 같습니다.

| scalar sample 수 | effective DAC code | 면적 |
|---:|---:|---:|
| 584 | −3066 | −1,790,544 |
| 1 | −402 | −402 |
| 7 | 0 | 0 |
| 합계 592 | | −1,790,946 |

따라서 정수 모델의 보상 후 면적은 0입니다. 592 sample / 4800 MHz = **123.333 ns**이며, RC까지 포함한 대부분의 DC 구간은 약 −296.348→−299.968 mV입니다. 마지막 잔여 면적 sample과 zero padding은 별도로 포함됩니다. 이는 실제 아날로그 면적을 적분한 결과가 아닙니다.

| 항목 | Point 5050의 HOLD 시작 기준 |
|---|---:|
| 모델 DC 시작 | +21.363333 µs |
| 모델 DC 종료 | +21.486667 µs |
| 직전 native scope sample | +21.103958 µs |
| 다음 native scope sample / 원시 spike | +21.603958 µs |

기존 scope 간격은 **500 ns**여서 모델 DC 창 안에 native sample이 0개입니다. 기존 `analyze_physical.py:245–254`는 모델도 이 native sample 시각에서만 평가하여 선으로 연결했습니다. 그래서 모델에는 있는 −300 mV 펄스가 주황색 선에서는 사라졌습니다. 새 그림은 동일한 명령 모델을 실제 구간 경계와 DC scalar sample에서 표시해 이 누락을 보여 줍니다.

원시 spike sample은 고정 offset 보정 후 **CH1 −294.560696 mV, CH2 −301.255258 mV**입니다. 해당 sample은 기존 전역 정렬상 모델 DC 끝보다 **117.292 ns 뒤**에 있습니다. 크기와 발생 순서는 예정된 DC 펄스에 부합하지만, 500 ns 간격의 한 sample만으로 실제 펄스 폭·면적·지연을 분리할 수 없습니다. 기존 DC 중앙창 검사도 0 sample로 **INCOMPLETE**이며 그대로 유지합니다. 모델선의 표시 누락을 해결했다고 이 불확실성을 PASS로 바꾸지 않았습니다.

## 2. 고정시간 30 µs / RC τ20 µs의 Point 9999

실행 순서는 `axis0`가 느린 바깥 축이고 `axis1`이 빠른 안쪽 축입니다. 따라서 마지막 두 포인트는 아래 순서로 실행됩니다. 동일한 identity matrix를 사용합니다.

| Point / 축 인덱스 | DAC4 / CH1 요청 | DAC5 / CH2 요청 | 정수 nominal DAC4 / DAC5 |
|---|---:|---:|---:|
| 9998 / (99,98) | +300 mV | +293.939394 mV | +300.555 / +294.489111 mV |
| 9999 / (99,99) | +300 mV | +300 mV | +300.555 / +300.555 mV |

두 HOLD의 간격은 18,768 fabric cycle = **62.56 µs**입니다. 직전 Point 9998은 양의 파형을 출력했으므로 DC 보상은 음의 방향입니다. 30 µs DC 명령은 cycle 187653358이며 실제 word는 `014b0000000000000000232800007482296a44b8`입니다. 양 채널의 정수 보상은 각각 아래와 같습니다.

- DAC4: `101954 × (−1127) + 42046 × (−1126)`; 원래 면적 +162,245,954를 정확히 상쇄합니다.
- DAC5: `139362 × (−1104) + 4638 × (−1103)`; 원래 면적 +158,971,362를 정확히 상쇄합니다.

| 이벤트 | 프로그램 시각 | Point 9999 HOLD 기준 |
|---|---:|---:|
| Point 9998 HOLD | 625489.973333 µs | −62.560000 µs |
| Point 9998 DC 시작 | 625511.336667 µs | −41.196667 µs |
| **기존 Point 9999 그림 시작** | **625540.426667 µs** | **−12.106667 µs** |
| Point 9998 DC 종료 | 625541.336667 µs | −11.196667 µs |
| Point 9999 SET 0 출력 | 625541.530000 µs | −11.003333 µs |
| Point 9999 상승 RAMP 시작 | 625551.530000 µs | −1.003333 µs |
| Point 9999 HOLD | 625552.533333 µs | 0 |

기존 그림은 첫 SET 명령보다 1 µs 앞부터 자르므로 **직전 DC 꼬리 약 0.91 µs를 함께 보여 줍니다.** 반면 모델은 Point 9999 한 개만 생성하고 현재 origin 이전은 0으로 반환합니다. 따라서 그림 왼쪽의 파란 −100 mV 부근에 대응하는 이전 모델만 빠진 것입니다. Point 9999 자체가 −100 mV로 시작하도록 명령된 것은 아닙니다.

실제 첫 두 sample과 **직전 Point 9998 모델**을 같은 전역 시각에서 비교하면 다음과 같습니다. 새 정렬이나 offset 조정은 없습니다.

| −11.509483 µs | −107.112980 / −108.403301 mV | −107.112980 / −106.250889 mV |

## 표시 문제의 범위와 증거

기존 대표 그림 `plots()`의 범위 문제입니다. `command_expectation.py:69–73,141`은 현재 shot의 모델을 만들고, `compact_expectation.py:119–121,143–144`는 origin 이전을 0으로 반환합니다. 이전 포인트의 tail을 연결한 새 그림은 이 의미 차이를 명시합니다. 중앙 HOLD 판정은 `roi_row():154–164`의 현재 포인트 중앙 5 µs만 사용하므로, 이번 두 대표 그림의 표시 문제 때문에 그 판정값이 바뀌지는 않습니다. 기존 DC 및 post-DC 결과도 덮어쓰지 않았습니다.

`review_results.json`에는 선택 포인트들의 전체 명령과 원시 주변 sample을, CSV에는 각 native sample의 시각·전압·현재/이전 모델 값을 보존했습니다. JSON의 `model_dc_range_mv`는 Point5050에서는 현재 DC 전체 592 scalar sample의 범위, Point9999에서는 **직전 DC의 마지막 scalar sample 한 개**를 뜻합니다. 후자는 전체 DC 최소/최대값이 아닙니다. 파란 sample 사이의 선은 표시용 연결이며, 중간 원시 sample을 생성하거나 펄스 폭을 복원한 것이 아닙니다.

분석 입력 23개 해시를 실행 전후 대조했고 동일했습니다. Python 종료 코드는 0입니다. 기존 원시 파형·명령·모델·분석 소스·기준은 그대로이며 새 그림과 문서만 이 폴더에 추가했습니다.
